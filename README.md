# EonMirth Flashlight

This contains everything you need to run your app locally.

An EonMirth privacy-first Android flashlight product. The web interface previews the experience and exports the native Android source project.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`

## Build an APK without Android Studio

Push this repository to GitHub and run **Actions → Build Android APK**. The workflow creates a downloadable testing APK. See [ANDROID_RELEASE_CHECKLIST.md](ANDROID_RELEASE_CHECKLIST.md) for the release steps.
