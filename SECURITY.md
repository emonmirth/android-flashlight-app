# Security Policy

## Supported Versions

Only the latest version of Glim is supported for security updates.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Glim, please send an e-mail to eonmirth@gmail.com. All security vulnerabilities will be promptly addressed.

We encourage you to use a private communication channel to report vulnerabilities so we can address them before they are publicly disclosed.
